# G1DE — Data Engineering Training

Welcome to the G1DE Data Engineering training repository.

This repository is the central learning hub for our batch. It contains class materials, practical coding examples, homework assignments, and student submissions.

## 📚 Repository Structure

| Folder | Description |
|---|---|
| [Classes](./classes/) | Topic-wise class notes, code examples and practical exercises |
| [Homework](./homework/) | Assignments and practice problems |
| [Submissions](./submissions/) | Student homework solutions |

## 🎯 Learning Approach

Our training follows a hands-on approach:

- Understand concepts through practical examples.
- Write and execute code during classes.
- Practice independently through homework.
- Build problem-solving skills through regular coding.

## 🛠️ Technologies

- Python
- SQL
- PySpark
- Data Engineering concepts

## 📌 Guidelines

1. Follow the topics in the order they are published.
2. Execute the examples rather than just reading the code.
3. Complete homework assignments within the given deadlines.
4. Keep submissions organized using your assigned student folder.
5. Ask questions whenever you encounter difficulties.
